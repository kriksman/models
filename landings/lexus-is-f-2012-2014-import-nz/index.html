Goo-net Exchange указывает длину 4660 mm и ширину 1815 mm для 2012–2014 IS F. Такой формат помогает, если автомобиль будет ездить не только по открытой трассе, но и по обычным NZ дорогам.

Fitted technology04

Under the skin

Для IS F важны не украшения, а точная mechanical specification: код кузова, V8, автомат и FR.

01

2012–2014 USE20 production scope

Подбор ограничен Lexus IS F с кодом USE20 за 2012–2014 годы. Goo-net Exchange указывает период с 2012-08 до 2014-07-23 для этого кода. Это важно при поиске: похожие внешне IS с другим кодом кузова в этот подбор не входят. Перед ставкой код DBA-USE20 должен быть подтверждён по конкретному автомобилю.

02

2UR-GSE 5.0 V8

Для USE20 Goo-net catalogue указывает 2UR-GSE, 5.0 V8 DOHC petrol, объёмом 4968 cc. Это центральная часть характера IS F: большой V8 в сравнительно компактном седане. Выходная мощность конкретной машины подтверждается по её аукционной информации, если этот параметр важен для ставки. Состояние конкретного двигателя не выводится из модели, оно рассматривается только по информации конкретного листинга.

03

8AT and FR layout

Goo-net catalogue указывает 8-ступенчатый automatic transmission и FR, то есть переднее расположение двигателя с приводом на задние колёса. Такая компоновка даёт более чистое рулевое ощущение, потому что передняя ось не передаёт тягу. Для покупателя это один из главных аргументов IS F как performance-седана, а не просто Lexus с большим мотором.

Questions before importing

Можно ли искать именно Lexus IS F Dynamic Sport Tuning USE20?
Да, но наличие нужно проверять по текущим аукционам. Goo-net Exchange указывает Dynamic Sport Tuning под DBA-USE20, а отличия конкретного автомобиля подтверждаются по его листингу.
Сколько стоит привезти IS F в NZ?
Цена считается по живому аукционному примеру и текущей importing estimate перед ставкой. Без конкретного автомобиля нельзя дать честный итоговый landed cost.
Можно ли заранее знать, что автомобиль пройдёт NZ entry certification?
Import viability must be checked for the exact model code and vehicle before bidding; final certification occurs in NZ. Итог зависит от конкретного автомобиля, документов, состояния, изменений и проверок после прибытия.
Сколько занимает импорт после покупки на аукционе?
Срок зависит от даты покупки, доступного судна, обработки документов, customs clearance и этапов после прибытия в NZ. Мы даём обновления по ходу процесса вместо обещания фиксированной даты заранее.
Что вы смотрите в аукционной информации?
Мы переводим и объясняем доступный листинг аукциона: grade, пробег, записи о состоянии, отмеченные повреждения, модификации и любые приложенные записи. Если информации нет или она неясна, мы так и говорим.
